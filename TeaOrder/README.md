

| 难点                        | 建议方案                                                     |
| --------------------------- | ------------------------------------------------------------ |
| 中杯/大杯算一个还是两个商品 | 建议用规格(SKU)模式：一个商品（珍珠奶茶）+多个规格（中杯￥12、大杯￥15） |
| 第二杯半价怎么算？          | 建议采用最低价半价：买3杯时，最便宜的那杯半价。这样逻辑简单，顾客也满意 |
| 会员折扣和活动能否叠加？    | 建议不叠加，优先使用优惠力度大的。例如：原价￥40，满30减5后￥35；银卡95折后￥38，那就用满减 |
| 升级后本单享受折扣吗？      | 建议下次生效，避免订单金额反复计算的复杂逻辑                 |



用户操作流程：
┌─────────────────────────────────────────────────────┐
│ 1. POST /products/upload-image                      │
│    → 上传图片到OSS (ref_count=0)                    │
│                                                     │
│ 2. POST /products (body: {image_id: 123})          │
│    → 创建产品 + 关联图片 (ref_count=1)              │
│                                                     │
│ 3. PUT /products/{id} (body: {image_id: 456})      │
│    → 更新产品                                        │
│    → 自动清理旧图123 (ref_count=0 → 删除OSS文件)    │
│    → 关联新图456 (ref_count=1)                      │
│                                                     │
│ 4. DELETE /products/{id}                            │
│    → 删除产品                                        │
│    → 清理关联图片 (ref_count=0 → 删除OSS文件)       │
│    → 删除规格、SKU、材料                             │
└─────────────────────────────────────────────────────┘

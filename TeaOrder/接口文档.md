## 一、全局约定

```yaml
BaseURL: /api
Content-Type: application/json
Authorization: Bearer {token}  # JWT Token

# 统一响应格式
Success:
  code: 200
  message: "success"
  data: {}

Error:
  code: 400|401|403|404|422|500
  message: "错误描述"
  data: null
  errors: [{field: "email", message: "请输入QQ邮箱"}]  # 校验错误时返回
```

### 错误码速查

| HTTP | Code | 场景           |
| :--- | :--- | :----------- |
| 200  | 200  | 成功           |
| 400  | 4001 | 参数缺失/格式错误    |
| 400  | 4002 | 验证码错误或已过期    |
| 400  | 4003 | 邮箱已被其他会员绑定   |
| 400  | 4004 | 发送过于频繁，请稍后再试 |
| 401  | 4010 | Token无效/过期   |
| 403  | 4030 | 权限不足（非管理员）   |
| 404  | 4040 | 顾客/订单不存在     |
| 422  | 4220 | 库存不足         |
| 422  | 4221 | 活动不适用（未满门槛）  |
| 500  | 5000 | 服务器内部错误      |

### 3.2 POST /api/customers/{id}/send-verify-email — 发送QQ邮箱验证邮件 ⭐

**说明：** 顾客提供QQ邮箱后，发送6位数字验证码。验证码存 **Redis**，5分钟有效。

**请求体：**

```json
{
  "email": "123456789@qq.com"
}
```

**业务校验：**

- 邮箱格式：必须以 `@qq.com` 结尾
- 该邮箱未被其他已验证会员绑定
- 同一顾客60秒内不能重复发送（Redis 防刷）

**Redis 存储：**

```
Key:   verify_code:customer:{customer_id}
Value: 847291
TTL:   300 秒（5分钟）
```

**邮件内容示例：**

```
主题：【xx奶茶店】会员激活验证码

尊敬的李四您好：

感谢您注册xx奶茶店会员！

您的验证码是：847291
有效期5分钟，请勿泄露给他人。

如非本人操作，请忽略此邮件。

xx奶茶店
2026-05-09
```

**响应：**

```json
{
  "code": 200,
  "message": "验证码已发送至 123456789@qq.com，5分钟内有效",
  "data": {
    "email": "123456789@qq.com",
    "expires_in": 300
  }
}
```

**错误响应（发送过于频繁）：**

```json
{
  "code": 4004,
  "message": "发送过于频繁，请60秒后重试",
  "data": {
    "retry_after": 45
  }
}
```

### 3.3 POST /api/customers/verify-email — 验证邮箱激活会员 ⭐

**说明：** 顾客提供验证码，后端从 Redis 读取校验。验证成功即升级为会员，Redis 中验证码立即删除（用完即失效）。

**请求体：**

```json
{
  "customer_id": 1,
  "email": "123456789@qq.com",
  "code": "847291"
}
```

**后端逻辑：**

```php
// 1. 查询顾客
$customer = Customer::find($customer_id);

// 2. 从 Redis 读取验证码
$cacheKey = "verify_code:customer:{$customer_id}";
$cachedCode = Redis::get($cacheKey);

// 3. 校验验证码是否存在
if (!$cachedCode) {
    return error('验证码已过期，请重新获取');
}

// 4. 校验验证码是否正确
if ($cachedCode !== $code) {
    return error('验证码错误');
}

// 5. ✅ 验证通过，立即删除 Redis（用完即失效）
Redis::del($cacheKey);
Redis::del("verify_code:limit:{$customer_id}"); // 清除发送限制

// 6. 更新顾客为会员
$customer->update([
    'email' => $email,
    'type' => 'member',
    'is_verified' => true,
    'became_member_at' => now()
]);
```

**响应（成功）：**

```json
{
  "code": 200,
  "message": "邮箱验证成功，您已成为正式会员！",
  "data": {
    "customer_id": 1,
    "name": "李四",
    "email": "123456789@qq.com",
    "type": "member",
    "level": "none",
    "discount_info": "暂无折扣，累计消费满100元升银卡（95折）",
    "next_level": {
      "name": "银卡",
      "need_amount": "100.00",
      "discount": "95折"
    }
  }
}
```

**响应（失败）：**

```json
{
  "code": 4002,
  "message": "验证码错误或已过期",
  "data": null
}
```

## 四、点单模块

### 4.1 POST /api/orders — 创建订单

**说明：** 核心接口。自动计算优惠、会员折扣、扣减库存、更新会员累计消费。

**请求体：**

```json
{
  "customer_id": 1,
  "items": [
    {
      "product_spec_id": 3,
      "quantity": 2
    },
    {
      "product_spec_id": 5,
      "quantity": 1
    }
  ],
  "activity_id": null,
  "remark": "少冰，多糖"
}
```

**计算逻辑详解：**

```
步骤1：计算原价
  杨枝甘露(大杯) × 2 = 22.00 × 2 = 44.00
  生椰拿铁(中杯) × 1 = 18.00 × 1 = 18.00
  原价 original_amount = 62.00

步骤2：判断活动优惠（如传了 activity_id）
  活动A：满30减5 → 62 ≥ 30，优惠5元，实付57元
  活动B：第二杯半价 → 最低价的1杯半价 = 18/2 = 9元优惠，实付53元

步骤3：判断会员折扣（和活动不可叠加，取最优惠）
  顾客当前等级：gold（9折）
  会员折扣后 = 62 × 0.9 = 55.80元
  对比活动优惠：55.80 < 57，取会员折扣

步骤4：更新会员累计消费（事务内）
  total_spent += 55.80 → 680.00
  检查升级：满1000升钻石？否，保持gold
  这笔订单本身享受gold折扣（按下单时等级快照）

步骤5：扣减原料库存（根据配方表 product_materials）
  杨枝甘露(大杯) × 2：
    - 芒果浆 100ml × 2 = 200ml
    - 椰奶 80ml × 2 = 160ml
    - 西米 50g × 2 = 100g
  生椰拿铁(中杯) × 1：
    - 咖啡液 30ml × 1 = 30ml
    - 椰奶 150ml × 1 = 150ml
  写入 stock_change_logs

步骤6：生成订单快照
  记录下单时的商品名、规格名、单价（防后续改价纠纷）
```

```json
  "message": "订单创建成功",

    "customer": {
      "name": "李四",

      "level": "gold"
    },
    "items": [
      {
        "product_name": "杨枝甘露",
        "spec_name": "大杯",
        "quantity": 2,
        "unit_price": "22.00",
        "subtotal": "44.00"
      },
```

## 七、员工管理模块

### 7.1 POST /api/stores/{store\_id}/employees — 添加门店员工

**权限：** director（经理）、manager（店长）

**说明：** 为指定门店添加店员。**店长只能添加店员，不能添加店长**；经理可以添加店长和店员。**一个门店只能有一个店长**。

**请求体：**

```json
{
  "name": "张三",
  "phone": "13800138000",
  "password": "123456",
  "role": "manager"
}
```

**参数说明：**

| 参数       | 类型     | 必填 | 说明                       |
| :------- | :----- | :- | :----------------------- |
| name     | string | 是  | 员工姓名                     |
| phone    | string | 是  | 手机号，唯一                   |
| password | string | 是  | 登录密码                     |
| role     | string | 是  | 角色：manager(店长)/staff(店员) |

**业务规则：**

- 一个门店只能有一个店长（role=manager）
- 如果该门店已有店长，再添加店长会返回错误
- 店员（role=staff）可以有多个

**响应（添加店长成功）：**

```json
{
  "code": 200,
  "message": "店长添加成功",

    "store_id": 1,
    "status": "active",
    "created_at": "2026-05-13T14:00:00Z"
  }
}
```

**响应（添加店员成功）：**

```json
{
  "code": 200,
  "message": "店员添加成功",
```

## 九、Redis 缓存设计

### 8.1 验证码存储

```
Key 格式:   verify_code:customer:{customer_id}
示例:       verify_code:customer:10086
Value:      847291  (6位随机数字)
TTL:        300 秒 (5分钟)

Key 格式:   verify_code:limit:{customer_id}
示例:       verify_code:limit:10086
Value:      1
TTL:        60 秒 (防刷限制，60秒内不能重复发送)
```

### 8.2 操作流程

```
发送验证码:
  1. 检查 verify_code:limit:{id} 是否存在
     → 存在: 返回 "发送过于频繁，请xx秒后重试"
     → 不存在: 继续
  2. 生成6位随机码
  3. 存入 Redis: verify_code:customer:{id} = 847291, TTL=300
  4. 设置防刷: verify_code:limit:{id} = 1, TTL=60
  5. 发送邮件

验证验证码:
  1. 从 Redis 读取 verify_code:customer:{id}
     → 不存在: 返回 "验证码已过期"
  2. 比对验证码
     → 不匹配: 返回 "验证码错误"
  3. ✅ 匹配成功
     → DEL verify_code:customer:{id}    (用完即失效)
     → DEL verify_code:limit:{id}       (清除限制)
     → 更新数据库: type='member', is_verified=true
```

### 8.3 Laravel 代码示例

```php
// 发送验证码
public function sendVerifyEmail(Request $request, $customerId)
{
    $request->validate(['email' => 'required|email|ends_with:@qq.com']);

    // 防刷检查
    $limitKey = "verify_code:limit:{$customerId}";
    if (Redis::exists($limitKey)) {
        $ttl = Redis::ttl($limitKey);
        return error("发送过于频繁，请{$ttl}秒后重试", 4004);
    }

    // 生成验证码
    $code = random_int(100000, 999999);
    $codeKey = "verify_code:customer:{$customerId}";

    // 存入Redis，5分钟过期
    Redis::setex($codeKey, 300, $code);
    Redis::setex($limitKey, 60, 1);

    // 发送邮件
    Mail::to($request->email)->send(new VerifyCodeMail($code));

    return success(['email' => $request->email, 'expires_in' => 300]);
}

// 验证验证码
public function verifyEmail(Request $request)
{
    $request->validate([
        'customer_id' => 'required|integer',
        'email' => 'required|email',
        'code' => 'required|string|size:6'
    ]);

    $customer = Customer::findOrFail($request->customer_id);
    $codeKey = "verify_code:customer:{$request->customer_id}";

    // 读取验证码
    $cachedCode = Redis::get($codeKey);
    if (!$cachedCode) {
        return error('验证码已过期，请重新获取', 4002);
    }

    // 校验验证码
    if ($cachedCode !== $request->code) {
        return error('验证码错误', 4002);
    }

    // ✅ 验证通过，立即删除Redis（用完即失效）
    Redis::del($codeKey);
    Redis::del("verify_code:limit:{$request->customer_id}");

    // 激活会员
    $customer->update([
        'email' => $request->email,
        'type' => 'member',
        'is_verified' => true,
        'became_member_at' => now()
    ]);

    return success([
        'customer_id' => $customer->id,
        'type' => 'member',
        'level' => $customer->level,
        'discount_info' => '暂无折扣，累计消费满100元升银卡（95折）'
    ]);
}
```

## 十、关键业务规则

### 9.1 会员身份规则

| 身份               | 条件           | 权益        |
| :--------------- | :----------- | :-------- |
| **普通顾客 (guest)** | 只填了手机号，未验证邮箱 | 可正常点单，无折扣 |
| **会员 (member)**  | 验证QQ邮箱后激活    | 按等级享受折扣   |

### 9.2 优惠计算规则

| 场景             | 规则                                    |
| :------------- | :------------------------------------ |
| **第二杯半价**      | 买N杯，价格最低的那1杯半价。买2杯半价1杯，买3杯仍只半价1杯      |
| **满减活动**       | 满X元减Y元，按原价计算是否满足门槛                    |
| **会员折扣 vs 活动** | ❌ 不可叠加，系统自动取最优惠方案                     |
| **升级判定**       | 累计消费满100银卡/满500金卡/满1000钻石，**下一笔订单生效** |
| **订单折扣快照**     | 记录下单时的等级和折扣率，防止中途升级导致纠纷               |

### 9.3 验证码规则

| 规则   | 说明             |
| :--- | :------------- |
| 存储位置 | Redis，不存数据库    |
| 有效期  | 5分钟（300秒）      |
| 使用次数 | 只能用1次，验证成功立即删除 |
| 发送频率 | 同一顾客60秒内只能发1次  |
| 邮箱限制 | 仅支持 `@qq.com`  |

### 9.4 库存扣减规则

| 场景          | 操作                                                   |
| :---------- | :--------------------------------------------------- |
| **正常销售**    | 按配方表扣减原料，写入 `stock_change_logs`，类型 `order_deduction` |
| **产品下架-报废** | 手动扣减，类型 `product_archive_scrap`，需备注原因                |
| **产品下架-返还** | 原料回库，类型 `product_archive_return`                     |
| **原料过期**    | 手动扣减，类型 `expired_scrap`，需拍照上传                        |
| **库存预警**    | `stock <= warning_stock` 时，看板显示红色警告                  |

### 9.5 会员等级规则

| 等级   | 累计消费    | 折扣  |
| :--- | :------ | :-- |
| 普通顾客 | -       | 无   |
| 银卡   | ≥ ¥100  | 95折 |
| 金卡   | ≥ ¥500  | 9折  |
| 钻石卡  | ≥ ¥1000 | 85折 |
